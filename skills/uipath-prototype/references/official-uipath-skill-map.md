# Official UiPath Skill Composition

Verified against `UiPath/skills` on 2026-07-30 at commit `a4941fffde9e045354e9df2190d529bef0ab7158`. Product commands, schemas, validation, live operations, policy changes, and current platform contracts belong to official skills. This complementary suite supplies project engineering disciplines around them.

- **`uipath-admin`** - Identity, authorization, tenant/service administration, IP restrictions, and organization/tenant audit. Status: in-development.
- **`uipath-agents`** - Build, evaluate, package, and deploy low-code or coded UiPath agents. Status: in-development.
- **`uipath-api-workflow`** - Author, validate, run, package, and publish API Workflow projects. Status: in-development.
- **`uipath-automation-discovery`** - Mine organizational systems for automation opportunities and size them. Status: preview.
- **`uipath-coded-apps`** - Build coded web apps and coded action apps. Status: preview.
- **`uipath-connector-builder`** - Author and publish Integration Service connectors. Status: in-development.
- **`uipath-feedback`** - Submit confirmed UiPath product, CLI, or skill feedback. Status: stable.
- **`uipath-functions`** - Build deterministic Python or JavaScript coded functions. Status: preview.
- **`uipath-governance`** - Author, deploy, inspect, and diagnose UiPath governance policies and compliance settings. Status: in-development.
- **`uipath-human-in-the-loop`** - Design approval, escalation, and validation task experiences. Status: in-development.
- **`uipath-insights`** - Query job monitoring KPIs, trends, and aggregated failure analytics. Status: preview.
- **`uipath-ixp`** - Set up, label, improve, and publish IXP extraction projects. Status: in-development.
- **`uipath-maestro-bpmn`** - Author and operate Maestro BPMN processes. Status: in-development.
- **`uipath-maestro-case`** - Author case management plans from solution designs. Status: in-development.
- **`uipath-maestro-flow`** - Author, validate, run, and publish Maestro Flow projects. Status: in-development.
- **`uipath-mcp-servers`** - Register AgentHub MCP servers and author resource tools. Status: in-development.
- **`uipath-planner`** - Turn process knowledge into an SDD and canonical multi-skill task plan. Status: preview.
- **`uipath-platform`** - Operate Orchestrator, Integration Service, Data Fabric, LLM Gateway, traces, and licensing. Status: preview.
- **`uipath-review`** - Run read-only structural, quality, specification, and best-practice review. Status: preview.
- **`uipath-rpa`** - Build, validate, run, debug, and test XAML or coded RPA projects. Status: preview.
- **`uipath-solution`** - Package, publish, deploy, and activate UiPath solutions. Status: preview.
- **`uipath-tasks`** - List, assign, reassign, and complete Action Center tasks. Status: preview.
- **`uipath-test`** - Manage Test Manager projects, cases, sets, executions, and reports. Status: in-development.
- **`uipath-troubleshoot`** - Run causal investigation across UiPath products and runtimes. Status: preview.
- **`uipath-project-discovery-agent`** - Discover UiPath project structure, dependencies, entry points, and conventions and return project context. Official agent under uipath-rpa.
