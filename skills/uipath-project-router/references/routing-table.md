# Routing Table

| Situation | Primary official owner | Complementary custom extension |
|---|---|---|
| Find enterprise automation opportunities | `uipath-automation-discovery` | `uipath-program-wayfinder` when major decisions remain |
| PDD, SDD, SOP, transcript, BPMN-as-input, or multi-project plan | `uipath-planner` | `uipath-discovery-with-docs` before planning when business decisions remain |
| Existing repository lacks project context | `uipath-project-discovery-agent` | `uipath-delivery-control-plane` after official context exists |
| RPA, agent, Maestro, coded app, API workflow, function, connector, or solution implementation | Owning official product skill | `uipath-task-refinement` only when an existing planner task is too large or blocked incorrectly |
| Artifact or solution quality review | `uipath-review` | `uipath-architecture-deepening` or `uipath-requirement-traceability` after the report |
| Runtime failure, error, hang, slowdown, or wrong result | `uipath-troubleshoot` | `uipath-regression-harness` after the symptom or cause is anchored |
| Test Manager operations and reports | `uipath-test` | `uipath-uat-session` only for facilitated business-language UAT observation capture |
| Action Center task operations | `uipath-tasks` | `uipath-observability-design` only for task-aging metrics and correlation design |
| Job KPI and failure trend analytics | `uipath-insights` | `uipath-observability-design` for future measurement design |
| Governance policies and compliance settings | `uipath-governance` | `uipath-solution-security-assessment` for project-level threats and evidence gaps |
| Identities, roles, tenants, IP restrictions, or audit events | `uipath-admin` | `uipath-solution-security-assessment` only to request evidence and record risk |
| Raw request or backlog item | Official owner after classification | `uipath-work-intake-triage` before official work begins |
| Release decision | Evidence from official owners | `uipath-release-readiness` aggregates; deployment stays with official owners |
| Cross-session continuity | N/A | `uipath-project-handoff` |
| Explicit question about which skill to use | N/A | `uipath-project-router` |
